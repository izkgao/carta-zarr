# PR 1 compatibility baseline

The first detector uses the profile ID `xradio.image` and the project baseline label
`1.2`. This label is deliberately a CARTA extraction baseline, not a claim that the
upstream Sky Image schema has a released `1.2` schema version.

The current reference fixture is generated by the CARTA backend fixture script with
`zarr-python==3.2.1`:

`../carta-backend/test/data/zarr-data-generator/generate_zarr_fixtures.py`

That script currently constructs the XRADIO-like metadata directly and does not import a
versioned XRADIO package or record an upstream XRADIO source commit. The detector therefore
claims compatibility with this fixture-derived profile only. Before broadening the claim,
the fixture generator and this document must record the exact upstream XRADIO revision that
produced the fixture. The upstream documentation currently lists Sky and Aperture Images as
schema design in progress: <https://xradio.readthedocs.io/en/latest/overview.html>.

The PR 1 tests cover:

- the existing backend minimal fixture when it is present beside this checkout;
- a valid profile with arbitrary stored axis order and `time > 1`;
- a valid non-XRADIO Zarr group;
- incomplete XRADIO-like metadata;
- missing stores and unsupported Zarr versions.
